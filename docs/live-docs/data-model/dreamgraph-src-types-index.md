# Index

> This module is the shared graph schema layer for DreamGraph entities and enrichment metadata, defining common shapes for features, workflows, data models, links, lifecycle state, and additive semantic fields written by enrichment passes. It exists so structurally discovered nodes can be stored in one compatible graph format and later enriched with intent, purpose, confidence, and provenance without breaking older consumers. In practice it is the contract that higher-level graph features such as `data_model`, `feature`, and `workflow` rely on, and it also serves as the source schema mirrored by consumer-facing projections like `dreamgraph_explorer_src_types`.
