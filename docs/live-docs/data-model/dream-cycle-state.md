# Dream Cycle State

> This node represents the runtime state model for the cognitive engine's overall cycle, capturing phases such as AWAKE, REM, NORMALIZING, and NIGHTMARE together with transition and introspection metadata. In the neighborhood it is the data counterpart to `cognitive_state_machine_workflow`, `stateful_cognitive_cycle`, and `cognitive_cycle`, while `rem_cycle_state` specializes the REM portion and `validation_outcome_history` reflects downstream consequences of state progression. It exists to make cycle control, monitoring, and safety boundaries explicit across dreaming, quarantine, normalization, and audit flows, though the exact fields beyond state and metadata are not evidenced here.
