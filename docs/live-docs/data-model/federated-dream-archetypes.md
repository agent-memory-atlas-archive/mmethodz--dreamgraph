# Federated Dream Archetypes

> This node represents the anonymized pattern artifact that DreamGraph instances exchange after local validation, carrying reusable architectural knowledge without exposing instance-specific names. In the neighborhood it is downstream of `dream_normalization_lifecycle`, `dream_validation_hub`, `fact_promotion_gate`, and `validation_outcome_history`, and upstream of exchange workflows such as `federated_dream_archetype_exchange`, `validated_archetype_exchange`, and `federated_pattern_ingestion`, which indicates it is the validated payload produced locally and then moved across federation boundaries. It exists to let `cognitive_federation` and related exchange hubs share distilled learning between instances while preserving privacy and supporting later integration.
