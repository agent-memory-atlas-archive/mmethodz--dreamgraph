# Validation Outcome History

> This node represents the longitudinal record of what happened to speculative dream outputs as they moved through validation and normalization, including whether candidates were promoted, rejected, or otherwise resolved across remediation cycles. In the neighborhood it is downstream of `dream_validation_hub`, `dream_normalization_lifecycle`, and promotion-gate concepts, and it also connects to `dream_cycle_audit` and `dream_cycle_metrics`, which suggest the history is useful for both forensic review and performance analysis. It exists to make validation behavior explainable over time rather than only at a single cycle boundary, though the exact event granularity and storage format are not evidenced here.
