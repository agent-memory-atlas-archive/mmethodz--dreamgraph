# UI Element Assignment Graph

> UI Element Assignment Graph is a mapping model that connects semantic UI elements exposed through the VS Code webview surface to registry-level contracts, categories, and related semantic metadata. It exists to normalize how concrete UI-facing elements are associated with platform-agnostic definitions so that rendering, migration, verification overlays, and plugin-driven registration can reason over the same element identities. In the neighborhood it sits between Semantic UI Element, Semantic UI Element Data Contract, and webview protocol definitions, and it also supports migration-oriented workflows by providing the correspondence layer needed to compare or port UI elements across platforms.
