# Semantic UI Migration Plan

> Semantic UI Migration Plan is the structured planning artifact for comparing semantic UI elements between a source and target platform and recording the resulting gaps, ported elements, evidence, and plan steps. It exists to make cross-platform UI migration explicit and reusable rather than leaving migration logic embedded only in registry operations or planner workflows. Within the neighborhood it serves as the data output of UI Semantic Migration Planner and related gap-analysis workflows, and it is closely aligned with Semantic UI Element as the unit being compared and transformed. The evidence boundary is limited to neighboring graph semantics and keywords, so this description stays at the level of planning structure and orchestration rather than asserting concrete fields or persistence behavior.
