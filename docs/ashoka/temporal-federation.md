# Temporal, causal and federated evidence — Slice 18

The core dependency handoff is verified. These rules reuse the existing temporal, causal, archetype and dirty-partition owners; no second job or trust authority is introduced.

`temporal_graph.json` (`dreamgraph.temporal_observations.v1`) retains exact historical tension readings, distinct `event_time` and `observed_at`, stable input digests and derived ancestry. Missing or ambiguous event time remains unknown. Legacy current urgency is observed at `last_seen`; it is never backfilled at `first_seen`. Reads do not create records. A tension publication commits its observations and correlation hypotheses together under the existing generation fence. Capacity blocks further writes rather than dropping history.

`causal_graph.json` (`dreamgraph.correlation_hypotheses.v1`) contains **hypotheses**, retaining distinct tension-onset pairs, policy, parents and stable IDs. Pairing does not reuse one effect to count several supports, and duplicated wrappers do not create observations. Common causes are not excluded; correlation is not evidence that changing one entity causes another to fail. Existing API names remain aliases. Historical event time determines deterministic replay; missing/out-of-range/ambiguous cycles are disclosed. At most 1,024 chronological onset events are analyzed, with truncation reported. No seasonality or urgency slope is invented from TTL.

`dream_archetypes.json` now has a v2 local envelope. Explicit v1 import attempts and unknown exchange versions are quarantined, with original bytes and artifact digest retained; existing local v1 stores require reviewed migration instead of being silently overwritten. Public resource views omit quarantined original bytes. v2 exchanges have a checked manifest, origin namespace and claim/source/evidence digests, event time, redaction policy and foreign validation claim. Imported records are local **hypotheses** with `local_validation: unreviewed`. Remote ancestry hashes are metadata, never independent local source roots. Repeated imports return their original durable operation outcome and cannot increase confidence or validation counts. Reuse of an origin ID with differing contents is quarantined rather than merged.

Exports use currently applicable validated insight projections and a fixed vocabulary for descriptions, roles and relations. Original prose, source paths, entity IDs, code and credentials are not exported. The namespace and digests are opaque correlation identifiers; this is redaction, not a cryptographic anonymity guarantee. Unredacted export is unsupported. Immutable exchange artifacts live in `federation/exports/`; manifests and artifact hashes remain with the existing archetype owner. A changed artifact blocks replay.

Known local target identities participate in bounded coalesced dirty generations. Unmapped foreign roles and unknown wider impact create a partial diagnostic and authorize no whole-graph or paid fallback. Source assertions remain separate. Local promotion still requires the existing claim-specific, current, independent source-evidence normalizer; repeated imports or model confidence cannot satisfy it. Scan age alone never marks these views stale.

Successive generations retain the union of unsettled target scopes, including while the older generation is running. Unknown impact stays pending until explicit reconciliation; a later narrow update cannot clear it. More than 100 coalesced targets blocks the transaction with a reconciliation requirement, preserving the original evidence and debt. A settled partition starts a fresh scope window.

Final consumer and qualification evidence remains with Slices 19, 20, 25, 26 and 27. No paid canary or live migration is implied by this document.

Correlation onsets and superseded hypotheses retain their original IDs and observation times. Late history publication refreshes hypotheses in the same transaction; exact session replay emits no additional cycle-completed event. Conflicting session IDs fail rather than overwrite history. Legacy analysis-only snapshots report unknown observation time.

DREAMGRAPH_FEDERATION is a shared typed JSON setting, applied to the next execution and preserved by template reset. It controls allow_import, allow_export, anonymize and an optional stable instance_id. Malformed settings and enabled unredacted export fail validation before persistence. Existing configuration count remains 308.
