# Curation and retention

Slice 16 dependency handoff is qualified by [wave evidence](wave-14-16-tests.json) and [native acceptance](wave-14-16-verification.json); final client controls remain later slices. `graph_maintenance.json` extends its existing metadata with `dreamgraph.curation.v1`: append-only typed dispositions, claim keys, reviewer/reason, prior decision and hash-bound reversible archives. Missing initial metadata is allowed; malformed existing metadata is unavailable and cannot reset decisions.

Reject/retire, archive and graph changes use one canonical journaled publication. The operator supplies expected graph revision, reason and an optional stable operation ID. Dry run does not write. Lost responses recover the committed decision; changed retry intent and competing revisions conflict. Current candidates overlay human dispositions without rewriting normalization cycles or deleting assessment history. Autonomous normalization and rediscovery respect durable suppressions; explicit reopen is required. Source age alone cannot create a rejection.

Human acceptance records a human assertion with zero independent source roots. It preserves assessments and does not relabel the assertion as verified source evidence. Restore replaces a rejected incarnation with the archived candidate, checks current endpoint identity, and conflicts if an endpoint disappeared or the subject changed. Reopen/restore cannot reactivate a historical promotion receipt: present factual applicability requires normalization committed after the reviewed decision. Retargeting archives and suppresses the original relationship and creates an explicit replacement proposal requiring revalidation; old proof cannot transfer to changed endpoints. `mutate_validated_edge` requires `reason` and `expected_revision`, supports `operation_id` and `dry_run`, and rejects missing/ambiguous/dangling endpoints.

Dream TTL applies to unvalidated speculation. Expiry archives nodes and their dependent speculative edges in the same publication, preventing dangling dream references. Source facts, promoted insight history and human assertions are not erased by dream TTL. Rediscovery cannot inherit confidence or source evidence from expired incarnations. `DG_MEMORY_TTL_CYCLES` defines the review window of speculative memory, not a truth-strengthening bonus. History remains inspectable.

Source-less quarantine also publishes its archive, affected graph stores and index together. Human contributions remain retained even if repository attribution needs clarification; ambiguous legacy identity blocks quarantine rather than guessing. Existing unrelated index families are preserved. Source reconciliation and evidence-currentness remain governed by their own source-effect receipts and are not inferred from full-scan time.

Owners: `src/cognitive/curation.ts`, `src/cognitive/graph-maintenance-state.ts`, `src/cognitive/engine.ts`, `src/graph/read-model.ts`, the normalizer and the canonical publication writer. Finished cross-surface curation/reopen controls and verified task closure remain later UI/agent slices.

`src/cognitive/cognitive-store.ts` owns operational snapshot reads: corrupt, malformed, unpublished or missing previously published state fails instead of becoming an empty history. The same canonical read barrier avoids observing a half-written publication.
