# Durable inference admission

Slice 6 places one durable admission boundary before daemon API, native API tool-loop, MCP sampling and native CLI dispatch. Policies keep the selected cognitive role, model, effort, output contract and retention request. No retry changes them or increases an allocation. `ModelExecution` pins the physical instance directory and immutable role policy; checkpoint continuations retain their run ID and cumulative allocation.

API run and daily amounts default to zero. Dispatch requires an exact operator-supplied `DREAMGRAPH_LLM_PRICING` record matching provider, model, currency and the role's `PRICING_VERSION`, plus positive role `RUN_BUDGET` and `DAY_BUDGET`. Tariffs contain a named source/version, input/output rates per million, and explicit inclusion of images/reasoning. They are not fetched automatically. Cached input is reserved at the undiscounted rate; reasoning is independently limited but stays inside output billing. These are conservative reservations and provider-usage estimates, not provider invoices. The shared daily pool belongs to this instance and billing principal; it is not an account-wide limit across unrelated DreamGraph instances.

All six roles expose `MAX_CALLS`, `MAX_INPUT_TOKENS`, `MAX_OUTPUT_TOKENS`, `MAX_REASONING_TOKENS`, `MAX_RETRIES`, `MAX_ELAPSED_MS`, `CONCURRENCY`, `MAX_HOPS`, `MAX_NEIGHBORS` and the two monetary allocations. Requests reserve full UTF-8 wire bytes plus framing as an input allowance and the requested output ceiling before external dispatch. This is an allocation heuristic rather than a measured tokenizer result; observed variance stops later admission for that principal. Output and reasoning reservations include image-bearing requests. Context and response byte limits prevent unbounded transport buffers.

The canonical `spend_ledger.json` records the pinned policy, run, UTC admission day, logical attempt, credential reference (never its secret), retained tariff, resources and state. Publication recovery and the physical writer owner serialize parallel reservations. Metadata accounting does not advance graph mutation time. A released reservation must be durably proven undispatched. Dispatched or uncertain attempts cannot be redispatched. Unknown token/cost fields retain their allocations through restart; unacknowledged requests also retain concurrency slots. Partial late usage cannot reduce previously observed counts. Cancellation prevents another dispatch and preserves committed graph work; it cannot claim that a remote provider stopped processing an already sent request.

Schema fallback consumes another admitted call and retry, under the original deadline. Refused, incomplete, invalid and HTTP error replies are settled before output validation; absent usage remains unavailable. Completion telemetry includes each actual dispatch attempt and its optional usage. Summaries never sum an absent metric as zero or double count cache/reasoning components.

CLI budgets count adapter invocations. Native internal inference counts and subscription currency consumption are unqualified; CLI execution is labelled `unmeasured_subscription`, with finite invocation/time/context bounds and reported native usage where available. An API tariff cannot establish subscription allowance consumption. Positive monetary allocations for an unmeasured subscription fail explicitly. Native process tree termination and supervised recovery qualify in Slice 17, and actual Computer Use model/image/action control qualifies in Slice 31.

Enrichment defaults to two hops; zero omits neighbors, and explicit depth must fit the selected role's hop ceiling. Neighbor caps apply even to high-degree hubs. Admission exhaustion or cancellation stops subsequent batches without generating deterministic replacement prose. Accepted batches and unfinished checkpoint scope remain durable. An explicit continuation reuses the checkpoint allocation; force re-enrichment creates new work with a new checkpoint and visible policy provenance. A changed policy requires an explicit new run. CLI output distinguishes unavailable usage and reports a safe stop reason.

The ledger refuses further reservations above its bounded retained-history capacity; it does not discard unknown liability. Job supervision, settlement review/archival controls and cross-surface transport/session authority remain Slices 11/17/23/25. Paid/model, other-platform and release qualification are separate gates. Offline test doubles and injected persistence faults do not qualify those gates.

Native-host admission is under implementation/qualification in Slice25. Five additive core-owned host contracts describe a pinned API/CLI binding, complete request, one-time permit, exact usage/termination report and read-only outcome. Generated editor/SDK copies consume these definitions. Original-host `/api/executions/v1/model/admit`, `/settle` and `/read` join the same durable `spend_ledger.json`; no new store, pricing authority or worker permission is introduced. Model transport and credentials stay in the native host. Permit delivery records possible dispatch liability, not proof of a provider request, measured context tokens or subscription cost. Missing/lost reports retain conservative counts/concurrency; read-only recovery cannot reconstruct launch authority. A report is a trusted host observation, never independent provider billing evidence. Native adapter adoption and complete conformance remain pending.

Ordinary editor API tool turns and wrap-up now scope final serialization through the original-host permit (under qualification). Complete whole UTF-8 wire reserves before local credentialed fetch; native streaming remains live with independent response/frame byte ceilings. Protocol completion, output acceptance, usage availability and termination uncertainty stay separate. A transport EOF or `[DONE]` alone cannot establish provider completion. Known original refusal is read back without redispatch. Continuation may reason from refreshed context naming this same pass's known source debt; this does not grant effect authority or permit unknown/foreign debt. Local requests carry a finite output ceiling; fragmented local NDJSON is parsed without dropping malformed evidence. Other native entry points/CLI/SDK callbacks and full conformance remain open.
# Native host callback adoption checkpoint

Editor Codex/Copilot launches now reserve one invocation through the original-host ledger after whole prompt delivery. The permit signal follows the native child; reporting is awaited separately from best-effort observers. A lost permit/report or unconfirmed cancellation stops continuation. Internal model requests, token output and subscription charges remain unmeasured; the output allowance is a conservative reservation, not an enforced native token ceiling. Positive currency allocations refuse without qualified subscription metering. Existing native process/stdout bounds remain separate.

SDK `ManagedGraphPass.runModel` uses this same ledger and returns native data verbatim. Its explicit host report records actual optional usage and protocol termination; merely settling a callback proves neither. Original request/report inspection and exact report retry cannot reconstruct dispatch authority. Cancel on Explain File/ADR Compliance propagates through original admission and native inference. The frozen engine regression passes1,799 cases/two existing skips/zero failures, with509 editor cases, builds and six checks passing; fourteen complete source hashes are in `slice-25-sdk-model-source-audit.json`. Native Node process ports are exercised without inference, while local provider replies, native executor reports and VSCode UI are declared fixtures. No paid/native-GUI/other-platform or complete GE/UX/client conformance is inferred.

The reviewed binding amendment permits `provider: none` only for a native CLI: it means the invocation does not attest a direct API provider. Requested model `auto` remains visibly unresolved; no routing/provider result is invented. Native API requests still require a real provider. Credentials, CLI configuration, native transport and account retention stay with the adapter; API continuation/storage/schema guarantees are not attributed to it. The shared role policy retains named adapter/model provenance and configured spend controls. Explicit original-host model/termination evidence remains distinct from callback settlement.

Unnamed local runtimes now share one `directoryInstanceId` fallback across the job, API model, HTTP authority and native-host admission owners. It hashes the same physical directory bytes into `directory:<sha256>`; named instance UUIDs are unchanged. A job from an older inconsistent unnamed identity still refuses admission rather than silently rewriting its persisted owner. Inspect and settle or recover that original job before starting replacement work. Computer Use may explicitly select its dedicated role, pinned during scope preparation; its policy remains in the same original job and spend ledger rather than borrowing an Architect allocation.
