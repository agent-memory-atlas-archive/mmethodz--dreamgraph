# Explorer evidence navigation — Slice 24

Verified scoped handoff; see [qualification packet](wave-24-29-verification.json). The daemon owns Explorer snapshot v2 and the canonical graph contract; the SPA consumes generated canonical validators. Product version remains 13.4.0 until the release gate. The v1 builder remains a named legacy fixture/comparison utility and is not the production endpoint. A v1 client must update rather than interpret v2 implicitly.

The production snapshot pins typed instance/kind/ID identities, assertion classes, revision, graph currency and current evidence to one immutable canonical read. Equal legacy IDs in different families remain distinct; legacy navigation rejects ambiguous aliases. A retained historical `validated_edges.json` label cannot produce validated styling without a currently applicable independent assessment. Human assertions and unknown confidence remain explicit. Node health is a topology proxy, not a correctness score.

Rendering has an explicit scope: at most 10,000 nodes, 30,000 relationships and 24 MiB. Omitted/excluded families and unresolved endpoints are counted. `state` describes view completeness; `canonical_state` retains the graph's actual state. `render_key` hashes drawable content; metadata-only publication changes update currency/evidence without rebuilding the layout. ETag hashes the complete view including revision/state. Polling, SSE hints and reconnect reread authority; older replies cannot replace a newer revision. Out-of-scope navigation reports the omission rather than guessing another node.

`GET /explorer/api/node/:canonical-id?etag=...&offset=...&limit=...` provides whole entity/evidence records and bounded adjacency pages (50 default, 100 maximum). A mismatched ETag returns `EXPLORER_REVISION_CONFLICT` (409). The context endpoint at `/explorer/api/context/:canonical-id?etag=...` uses the same `buildContextPack` as agent RAG: selected mandatory identity, depth 1, 12 neighbors, 24 records, allowance 3,000. Its estimator is an explicitly named UTF-8 byte upper bound; it does not claim measured model tokens. Inspecting context performs no model call or graph write and never sends it to Architect automatically.

Selected short labels remain whole. Label selection/collision layout is bounded; connection shaders, bloom, zoom attenuation and reduced-motion behavior preserve the existing glass presentation. Narrow layouts use explicit canvas/rail columns; collapsed rails remain 24 px. Array/detail disclosure and adjacency paging keep dense hubs navigable. Runtime rendering measurements describe this renderer, not graph correctness or agent task gain.

Core fixtures exercise typed collisions, same-revision RAG/context equivalence, a 260-neighbor hub, 10,005-node projection limits, metadata-only revision stability and real independent-proof withdrawal revoking validated styling. The disposable actual-daemon Chromium qualification uses 1,204 nodes/2,796 connections, long labels, software WebGL, keyboard/narrow/reduced-motion controls and dropped-reply/reconnect workflows. This is Windows Chromium/software-renderer qualification, not a claim about physical GPU performance, other browsers or native Computer Use.
