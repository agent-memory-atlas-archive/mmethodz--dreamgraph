# Cognitive policy evidence

The initial-scan, dreamer and normalizer profiles are independent. The operator may retain an economical initial scan and select a frontier model for established-graph cognition; model names are user choices rather than permanent ceilings. Parameter capability and admission still apply. Creative generation remains speculative, and semantic agreement does not establish independent source evidence.

Accepted LLM dream nodes/edges and normalizer semantic assessments retain prompt/schema versions and hashes, exact supplied source-context hash, cited-source/ancestry IDs, policy fingerprint, requested and reported model, provider/API/adapter/effort, retention request, elapsed time, response hash and actual admission telemetry. This attribution does not attest source correctness. Only hashes and IDs are embedded, avoiding duplicated raw prompts, source code or credentials in each candidate. Failed dispatch/unknown usage remains in the admission ledger; full failure artefact publication is later truth/job integration.

The reusable offline evaluator freezes reviewed source/claim/contradiction labels, preserves original outputs and counts factual errors, useful novel hypotheses, unsupported promotions, missed contradictions, abstentions and optional reported usage/latency. Contradictions are checked against all supplied evidence, including evidence the model did not cite. Repeated summaries of the same source share ancestry. Cost remains unmeasured without admitted real-provider settlement. Deterministic fixtures measure the evaluator, not model quality.

Paid and Computer Use canaries require separately approved source/image/DOM disclosure, retention and finite run/day allocations plus supervised execution. Evaluation mode does not grant these. The current normalizer is the measured baseline; source-truth promotion changes belong to Slice 15, composed agent/model comparisons to 27 and actual Computer Use qualification to 31. Skipped canaries remain unverified, and previous profiles remain selectable.
