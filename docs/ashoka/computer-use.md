The earlier per-task worker/profile setup below is not the current browser onboarding flow.

Additional platforms, runtimes and native desktop backends are explicitly deferred beyond v14.0.0. The existing original-host execution, session authority, C05 job owner and C15 publication journal own the work. Computer descriptors live in `execution_contexts.json`; there is no separate job database or agent scheduler. Before input, the broker records the exact action hash and external-effect intent. An uncertain reply stays unknown and an identical action returns its original receipt. GUI postconditions, graph reconciliation and slice verification are separate outcomes. Material project changes use the existing source observer and remain reconciliation pending until the graph owner commits them.

Scoped permission distinguishes observation and interaction. The reviewed target, profile digest, worker source, original execution and finite expiry are bound together. Preflight/selection creates no permission; an explicit operator confirmation creates the scoped grant. Full access still requires two confirmations and does not waive exact action approval, budget, evidence or termination rules. Model-worker credentials cannot call human control ports. Lost confirmation replies preserve the original expiry and revocation; they do not renew authority.

The portable browser worker uses optional `playwright-core@1.62.1`, an explicitly pinned Chromium executable/version and a fresh headless context. It receives no provider credentials or personal-browser profile. The private inherited IPC channel has an epoch, pairing nonce, sequence and replay checks. Stop and heartbeat bypass ordinary work. Browser closure and pending request disposal start concurrently. Lost stop replies retain the original peer for stop-only recovery; they cannot reopen input. An authenticated local watchdog report can confirm termination through the surviving original channel. A disconnected channel without that acknowledgement retains recovery, even when local containment succeeded.

Browser profiles describe allowed origins, segment paths, request methods, structural controls, postconditions, redactions and image limits. Frames/popups, daemon authority origins, downloads, file choosers, WebSockets, service workers and alternate network facilities are restricted at the worker. Navigation is separately enabled and stays within the approved origin/path. Structured references expire when the target or geometry changes. Screenshots are cropped/masked in the worker and transported ephemerally; linked pixel and structural descriptors contain hashes, not image bytes. Ordinary traces expose metadata rather than literal action arguments or raw DOM/pixels. Redaction is profile driven; it is not a claim that arbitrary secrets can always be recognized.

The original worker measures heartbeat age and Stop duration with monotonic time. Wall-clock corrections cannot suspend or falsely advance its watchdog. The2500ms heartbeat threshold,100ms check interval and existing Stop/control-loss ceilings are unchanged; absolute grant expiry remains separate. Failed qualification artifacts stay unqualified and retain only bounded completed-check IDs and a known worker phase when available, without arguments, nonces or raw evidence.

Private worker pairing has a finite fifteen-second cold-start window for module loading before any browser is opened. This startup allowance does not extend action deadlines, the one-second input-release or pause acknowledgement, the five-second termination/control-loss ceilings, or the original execution/grant expiry.

**Stop has two guarantees, explicitly approved by the maintainer on 2026-10-03.** Within one second, cancel further actions, release held input and relinquish control. The isolated worker closes its actual virtual input page before sending the authenticated input-release event; it never owns the native desktop seat. Confirmed termination of the original browser/worker tree may take up to five seconds from that same request. Bounded escalation targets only the originally launched process tree; physical browser closure, runtime closure and the termination helper's exit must be observed. The journal and Architect display `stopping` / **input released · confirming termination** until final proof arrives. Missing proof becomes `recovery_required` / **termination unconfirmed**, with the lifetime effect unsettled and original stop-only recovery retained. A release event, timer expiry, cancellation flag or termination-command return is not Stop complete. Delivered remote effects may still finish and remain separate from cancellation proof. Qualification records `stop_release_ms` and the separate BW04 `termination_ms`; previous accepted evidence retains its original measurement scope.

Native API Architect uses provider-neutral custom computer tools within its existing tool loop. The operator explicitly chooses the selected Architect model or the configured `computer_use` role. The latter's exact provider/model/API, retention policy, allocation and policy hash are shown and pinned during preparation; a changed policy requires a new preparation. It uses that role's durable model admission inside the original job and carries its cognitive instruction. No automatic model substitution occurs. Images must pass that exact provider/model's capability and admission; `nativePromptTextBytes` is a text-byte safety bound, not token accounting. Earlier image payloads are removed from subsequent local turns while descriptors/receipts remain. A lost daemon tool connection refuses the computer pass. Provider built-in/native tool mappings remain open integration work; a custom tool is not a claim of provider-native Computer Use qualification.

The compact browser row opens scope/limits and a private observation drawer only on demand. Opening it discovers the current owner's existing sessions through a bounded, snapshot-bound page from the existing execution store. Reloading or selecting a session issues no grant or new pass. The original execution and worker identity remain visible; an unavailable original worker leaves recovery unresolved. **Recheck original stop** uses only the retained original independent channel, with no input replay or renewed authority. Selection clears old pixels and ignores late results from the prior selection. Closed archived execution history is outside this reconnect list; durable receipts remain available through their original execution IDs. A prepared, confirmed scope applies to one new original pass. A native CLI request remains native and reports its missing conformance; it never silently receives the API harness. Source changes and unsupported OS/runtime/version/retention combinations invalidate preparation before activation.

A trusted SDK host may supply its existing `sessionBearer` to `ManagedExecutionClient`; the bearer stays in memory and cannot adopt a different browser owner.

The editor's compact **Computer Use** drawer remains closed and makes no startup request. Open it, refresh the owned list and select an original session to inspect. Missing workers remain visibly unavailable. The separate private `/api/executions/v1/computer-evidence/observation` port lets this owner explicitly inspect the original broker's existing capture. It cannot take a new capture, send input, create grants or expose another owner's evidence. The original control port remains image-free. Starting Computer Use within an editor pass remains integration work; this drawer alone does not qualify the complete editor execution loop or a native desktop backend.

**Pause** immediately fences new input and the next model call. An already dispatched atomic operation settles to its independently observed receipt before the worker acknowledges the boundary. The subsequent pause acknowledgement is bounded to one second; uncertainty triggers independent Stop and remains visible. **Resume** validates the original grant/job and takes fresh graph context and target evidence from that same worker. Old references and control fences cannot dispatch. The original deadline and usage continue throughout pause; resuming never renews a grant or replenishes a budget. Lost control replies can read back only the original cycle. Stop remains available while paused and breaks model waits without a provider roundtrip.

Changing the adapter, model role or interaction selection clears the pending preparation. Replies from an earlier setup, preparation or confirmation cannot attach that old scope to the new selection. Exact confirmation retries retain the original ID and finite expiry. Selecting a supervised GUI/source task checkpoint does not widen the independent C17 browser target grant; source reconciliation remains a separately approved graph-owner action.
