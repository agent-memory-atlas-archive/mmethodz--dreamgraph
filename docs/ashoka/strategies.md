# Strategy execution contract

The pure `src/cognitive/strategy-catalog.ts` owns names, descriptions, active/retired status and requirements. `strategy-registry.ts` dispatches the eleven actual executors. MCP discovery, `system://capabilities`, dashboard choices and adaptive selection share these definitions. Reflective had no executor: historical requests fail explicitly before decay or cycle changes; reviewed agent observations remain explicit graph mutations.

`max_dreams` bounds the combined speculative nodes, edges and newly raised shadow-table tensions. Integer allocation never manufactures a minimum allocation: zero/tiny totals stay bounded; explicit zero LLM/PGO fractions remain zero for `all`. Defaults are 35% LLM and 15% PGO, with structural executors sharing the remainder. A single named executor receives the full candidate budget. Model request/token/spend bounds independently use the admitted dreamer role. Candidate capacity does not authorize spend or factual promotion.

Focus IDs must resolve before a cycle changes state. Zero hops means precisely those roots; an unknown ID fails instead of selecting the full graph. This legacy structural strategy view explicitly covers features, workflows, data models and scanned datastores. Out-of-view links are omitted with a count; ambiguous untyped identities fail. This is not the complete 17-family agent retrieval contract. Dirty-region job selection and durable model/job cancellation compose through their owning Ashoka slices.

Each executor receives an isolated snapshot. Output validation rejects invalid endpoints, self-links, duplicate IDs, non-candidate trust and cap overflow. Missing-abstraction reserves a hub and at least two connections together. Hub deduplication returns an identity mapping so retained relationships refer to the existing node; rejected duplicates do not acquire new relationships. Unknown inverse semantics stay unsupported. Schema grounding does not mutate the fact snapshot, cap-zero creates no tensions, and ambiguous datastore matches never pick the first entry. A causal co-occurrence stays a hypothesis with zero seeded reinforcement. Provider errors/refusals are observable strategy failures.

Zero MCP candidate budget skips the cycle, including decay and normalization, without interrupting another cognitive state. Outcomes distinguish completed, failed and allocation-skipped strategies. Slice 14 persists post-dedup observations, bounded exploration and explicit reviewed usefulness in `meta_log.json`; see [strategy learning](strategy-learning.md). Slice 15 owns current independent source-evidence promotion guarantees.

Offline qualification uses actual positive/negative/empty/zero/tiny structural executors, seeded PGO, actual causal replay with historical input fixtures, response-port validation and actual two-cycle writer deduplication. Actual LLM parser/attribution fixtures use a provider double; they qualify schema, ancestry and bounds, not model usefulness. No paid canary or live graph scan is implied.
