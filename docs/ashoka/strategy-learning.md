# Strategy learning and retention

Slice 14 dependency handoff is qualified by [wave evidence](wave-14-16-tests.json) and [native acceptance](wave-14-16-verification.json); final task usefulness remains Slice 27. `meta_log.json` retains its existing analysis entries and adds `dreamgraph.strategy_portfolio.v1`: versioned, input-bound observations, post-dedup claim identities, ancestry, admitted attempts, measured charges, explicit usefulness reviews, allocation sequence and reset history. Missing initial state is empty; malformed existing state blocks instead of resetting learning.

One graph publication commits speculative nodes/edges and their portfolio observations. Repeated suggestions add neither novelty nor confidence nor TTL. Directed typed endpoints, repository and relation define edge identity; repository/category/name define speculative node identity. Novelty is separate from source corroboration and from labeled task accuracy. Canonical current evidence determines the operational corroboration count. Metacognition reports labeled accuracy as unavailable and cannot lower truth thresholds using its own promotion ratio.

Adaptive allocation preserves the configured model/stochastic shares and the combined candidate ceiling. Heuristic exploration rotates across persisted allocation sequence, including one-candidate budgets. Its exploration floor is one slot and a fraction of the heuristic allocation defined by `DG_PROBE_INTERVAL` (default one sixth). Explicit claim usefulness reviews affect bounded exploitation; consecutive completed barren runs reduce weight but retain exploration. Skipped allocations and dependency failures are not barren observations. `DG_BARREN_THRESHOLD`, `DG_PROBE_INTERVAL` and `DG_STRATEGY_HISTORY` are positive bounded counts. Fixed allocation remains an explicit fallback.

The internal portfolio review/reset port requires reviewer, reason and expected portfolio revision. Reset atomically archives the previous portfolio and preserves prior analysis. Hash-bound result artifacts return the original review result after later changes; changed retry intent conflicts. Capacity exhaustion requires reviewed reset, never silent evidence forgetting. Generated hub endpoints use semantic node identities, so expiry and new generated IDs cannot inflate novelty. Subscription or absent usage remains unmeasured; only settled tariff-bound provider usage is a measured charge. No external model call is used for these controls' offline qualification. Final usefulness comparisons remain Slice 27.
