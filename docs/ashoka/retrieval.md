# Canonical bounded context — Slice 3

`graph/context-pack.ts` builds task context from the canonical read model. It never calls or probes a model, writes a store, fabricates a fact, or infers freshness from elapsed time. RAG, automatic task compilation, cognitive preambles and `dream://context` consume this one interpretation. The resource retains the pack as one whole record, keeping metadata and evidence together.

Every entity uses instance/kind/repository/ID identity. Source assertions, human assertions, decisions, hypotheses, validated insights, tensions, historical evidence and unknown provenance retain their classes. Confidence is preserved, including null; it does not qualify a hypothesis as fact. Relevant decisions, selected plan/slice and required evidence reserve whole units first. Structured knowledge travels as separate whole fields with parent/evidence references. Long fields are omitted, not clipped. Emitted relationships require both endpoints in context.

Text and compact metadata have independent hard budgets. UTF-8 byte counting is a conservative token upper bound for byte-tokenizing adapters, including Unicode and serialization syntax. It supplies less text than a qualified model-specific tokenizer could; Slice 4 owns tokenizer qualification and usefulness measurements before tuning. Hops, neighbors and total records are bounded independently. Omissions have reason/count aggregates; records explain selection. Insufficient mandatory context does not become an accepted task preamble. Metadata overflow is an explicit error, never clipped JSON.

Receipts bind assembly to committed revision and requested scope. Delivery remains `unattested`: assembly does not prove an API/native CLI consumed it. Source fallback names unmapped paths or absent anchors, without claiming source reads or verification occurred. Adapter delivery, compression refresh and executed source fallback remain Slice 25 integration obligations.

Durable managed-source obligations inform scoped currency. Known source effects awaiting reconciliation make dependents stale; unresolved effects are unknown. Reconciled facts stay current while optional enrichment/digestion is pending. Malformed effect history is visibly unknown. Unaffected context does not inherit another source's debt. Old scan age alone never makes the graph stale.

C17 fixture observations retain source kind, verification, observed/expiry times and execution ownership. Expired/future observations are excluded. Included observations are semantic history, not coordinates or screenshot replay; their earliest expiry bounds the receipt. Actual invalidation, native-runtime recovery, action-time reobservation and platform GUI qualification remain Slice 31 work.

`representation: legacy` and `DG_GRAPH_CONTEXT_REPRESENTATION=legacy` preserve explicit old-retrieval comparison with visible limitations. Explicit canonical overrides the environment switch. New filters/mandatory controls fail in legacy rather than being ignored. Caller-supplied preamble evidence retains its compatibility path. This is not release-wide authority/adapter qualification or evidence of measured usefulness gains.

Slice 4 indexes documents, Unicode/symbol tokens, postings, evidence ancestry and sorted adjacency by instance, graph revision and full content identity. Reuse never crosses a changed payload with an unchanged revision. Eight cached entries and a 16 MiB estimated retention ceiling bound the cache; larger corpora use a transient correct index. The estimate is not a literal JavaScript heap guarantee. Legacy ranking also precomputes query statistics instead of repeatedly scanning all documents per term.

The frozen [paired-task protocol](agent-evaluation-protocol.json) retains twelve DreamGraph/Web64 labels and the content-addressed revision-7 baseline even as compatible core contracts advance. `npm run benchmark:retrieval` compares cached selection with rebuilt reference selection over repeated queries, with identical context, mandatory evidence and preregistered latency tolerances. Its [measurements](retrieval-benchmark.json) use frozen source excerpts with synthetic distractors; they do not measure live mature graphs or model latency. The matched evaluation harness freezes task/arm evidence, validates reported metrics, records refusal/unsupported claims and has bounded cancellation. Real-model execution remains blocked until the composed Slice 27 allocation and evaluation gate. Scores, shorter prompts and fewer rereads alone cannot establish material understanding gains.
