# Claim evidence and normalization

Slice 15 is verified for its dependency handoff. Native ADR-241 is the accepted **system-reviewed scoped amendment** to ADR-096 under the owner's approved Ashoka scope. It replaces the relaxed factual-evidence clause; the original entity-count OR cycle/time exit, 0.50 exploration ceiling, 24-hour maximum and exit-reason telemetry remain. No live migration follows from this decision.

`src/cognitive/normalization-evidence.ts` owns `normalization_evidence.json` (`dreamgraph.normalization_evidence.v1`). This registered graph store retains exact typed node/relationship claims, immutable observations, ancestry and separate withdrawal records. Source assertions, human assertions and generated judgments have different meanings. Human assertions and generated consensus do not become independent source corroboration.

The first internal source producer verifies an exact JSON-pointer observation `{claim, verdict}` in a configured repository, including SHA-256, typed claim and direction. It rejects paths/symlinks outside the repository, missing/changed bytes and mismatched claims. This is a source assertion, not a claim that arbitrary prose or adjacent keywords prove a relationship. It publishes through the existing physical writer, CAS journal and payload-bound operation receipts. A model-supplied `source_verified` flag cannot mint a root. Other parser/test/runtime producers require their own qualified decoders; no adapter can substitute a model-generated root.

Ancestry resolves only matching claims/verdicts, with cycle/missing-reference diagnostics. Copies and identical source content count once. Current conflicting source observations block promotion. Withdrawals preserve observations and receipts. Historical scan age is not a freshness rule; actual changed proof or known unreconciled scope is material. Bounds are explicit: 10,000 observations and withdrawals, 64 parents, 16 MiB ledger, 2 MiB source documents, finite aggregate source work and ancestry traversal. Exhausted proof remains unavailable, never fabricated evidence.

Qualification is pending: real source-producer/promotion integration, cold-start and independent positive/negative evidence, retained legacy evaluation, durable interruption/replay, and labeled calibration are required before Slice 15 can be verified. Full producer/client/job composition remains in Slices 17/25/27. No paid canary has run.

`src/cognitive/normalization-publication.ts` now coordinates current evidence, candidate history, dream scores, validated records and source-qualified entity/index writes in one transaction. Direct legacy engine promotion throws `NORMALIZATION_PUBLICATION_REQUIRED`. Runtime/provider failures propagate; no partial fact write is described as rolled back. Integration tests remain pending.

Calibration reports only current independent-root coverage as evidence completeness. Prose and nonzero legacy counts are not evidence. Labeled precision, recall, confusion matrix, Brier score and reliability bins require an explicit separate reviewed-label packet; absent labels stay unmeasured. Trust labels distinguish source assertion, human assertion and disputed claim.

Independent lineage is assigned by the internal source producer, separate from claim/model input; copies retain that lineage even if metadata changes. Identical content additionally collapses different declared lineages. This first decoder is a bounded declarative source-observation port, not a general code or runtime verifier. Current canonical promotion labels require the actual normalizer operation receipt and current matching proof; unqualified legacy promotions remain hypotheses.

Full pass outcomes use immutable `normalization-result-<operation-sha256>.json` artifacts committed with their participants. Small receipts attest the exact artifact hash; recovery verifies it and returns the original complete outcome. Admission bounds 10,000 artifacts and a conservative 16 MiB result envelope before semantic inference. Source work is bounded to 256 unique proofs, 32 MiB aggregate bytes and 2 MiB per file; ancestry visits each matching observation once, with at most 64 parents. Invalid claim ledgers make optional graph evidence explicitly partial rather than discarding unrelated graph families; normalization rejects malformed proof stores.

Operational calibration separates retained normalization/promotion history from current canonical trust. Recorded judgments alone do not claim current applicability. Precision/recall remain independent reviewed-label measurements.

Actual focused qualification now includes 21 normalization fixtures: independent source/node positives, identical-content/lineage collapse, model agreement without proof, contradictions, withdrawals, three-pass history projection, managed witness debt with unchanged bytes, physical directory aliases, large-result replay, publication interruption and provider cancellation. Latest source/graph pair passes 32 tests; full wave regression and native acceptance are still pending. The prior unfavorable structural baseline is retained unchanged in `cognitive-policy-report.json`.
